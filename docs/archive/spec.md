Scope: Operating system for a consulting / small business / biotech OS.

## Initial use cases
- Managing todo list
- Managing list of leads
- Email management (-> integration with gmail)
- Calendar management (-> integration with google calendar)
- Preparing, viewing and editing ppt (-> integration with Oria, Google Slides)
- Preparing, viewing, and editing doc (-> integration with google docs)
- Preparing, viewing, and editing excel (-> integration with Google Sheet)

## UX / UI
- Cantab OS -> initially available only as Claude.ai MCP app
- Later -> ChatGPT integration, front end
- Desired experience, mobile: chat + displayed app elements
- Desired experience, desktop: chat + displayed app elements, rendered web page in side window (url link provided by MCP)

## Overall architecture
- Cantab OS is BACKEND ONLY (i.e. DB + MCP edge function)
- Google integrations initially via Claude Code; but Cantab OS holds urls in DB
- Cantab OS as MCP server also instructs host (= Claude) how to display app elements and what to display in side window

## Database

### Skills
Table of skills = workflows. Columns: id, label, description, guideline

### Todos
Personal todos. Columns: id, label (todo:number), name, category, due, importance, status (boolean, true = done), context (maintained by the LLM)

### Leads
List of contacts / leads. Columns: id, label, name, full name, email, context (maintained by the LLM), url_linkedin

### Sheets / Docs / Slides
List of google worksheets. Columns: id, label, name, url (Google url), storage_url (slides only -> pdf url, stored in Supabase storage), context

## Tools

### list
Arguments: skills, todos, leads, sheets, docs, slides. Returns: all columns except id, context.

### get
Argument: array of labels. Returns all columns except id.

### write_todo, write_lead, write_sheet, write_doc, write_slide, write_skill
Fills all columns except id, context, label. Label is auto generated by backend SQL function. Returns confirmation or error.

### note
Argument: label, text. Appends context for label. Returns confirmation or error.

### important
Every tool also returns instructions how to render 'in chat' elements.
